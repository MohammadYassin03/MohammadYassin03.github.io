A Comparative Study of CNN, Transformer and Hybrid Architectures for ECG Arrhythmia Detection

We built and compared three deep-learning approaches for classifying heartbeats from the MIT-BIH Arrhythmia Database into four classes: Normal, Supraventricular, Ventricular and Fusion. About 89% of beats are Normal, so models were selected on macro F1 rather than accuracy.

Approach

  • 250-sample windows around each R-peak, plus patient metadata and RR-interval features
  • Partial SMOTE oversampling of minority classes; four augmentations for the hybrid model
  • CNN baseline on 64x64 log-magnitude STFT spectrograms
  • Transformer baseline on z-scored raw waveforms with patch embedding
  • Hybrid: pretrained EfficientNet-B0 patch tokens plus a metadata token fed to a Transformer encoder
  • Random hyperparameter search (15 configurations) per model

Results (test set)

CNN baseline138k0.9900.930

The small dual-branch CNN won on macro F1. The hybrid improved Supraventricular F1 but lost ground on the rare Fusion class.
