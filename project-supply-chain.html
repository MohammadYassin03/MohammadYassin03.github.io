Supply Chain Visibility Platform

Shipment trackers are unreliable across the Middle East, so we built a cloud platform for logistics companies running import and export flows in the region. Iraq is the demo environment: simulated trucks move between Basra Port, Umm Qasr and depots in Baghdad, Mosul, Erbil and Kirkuk.

Architecture

  • A Python simulator sends batches of shipment events to API Gateway
  • Lambda validates and normalizes each batch, writes it to DynamoDB, and archives the raw batch to S3
  • A Streamlit dashboard queries DynamoDB to show a live map, delivery-status breakdown and an active-shipments table
  • OSRM routing and distance-based ETA predictions flag detours and late deliveries

The full report covers data collection, cleaning, supervised and unsupervised analysis, and the AWS design.
